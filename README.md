# Kata-library

This project is using Hexagonal Architecture (Ports & Adapters) to ensure clean separation between business logic and infrastructure.

Features:
- Add new books to the catalog
- Borrow and return books  with optimistic locking
- Manage book copies with optimistic locking
- Store and retrieve book content from a NoSQL repository
- Manage relational data (books, authors, loans, users) in a SQL database
